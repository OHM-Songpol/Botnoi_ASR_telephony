## What to use where

| If you want to…                              | Use                                                                 |
|----------------------------------------------|---------------------------------------------------------------------|
| Submit a new result to the leaderboard       | [Benchmark submission issue](https://github.com/OHM-Songpol/Botnoi_ASR_telephony/issues/new?template=benchmark_submission.md) |
| Access the telephony test set                  | [Hugging Face dataset](https://huggingface.co/datasets/Botnoi/voicebot-telephony-speech)   |
| Report a bug in the evaluation harness        | [Bug report issue](https://github.com/OHM-Songpol/Botnoi_ASR_telephony/issues/new?template=bug_report.md) |
| Ask a general question                        | [Question issue](https://github.com/OHM-Songpol/Botnoi_ASR_telephony/issues/new?template=question.md)     |
| Discuss a commercial license or partnership  | Email the maintainers above                                         |
| Report sensitive data concerns                | Email the maintainers directly — **do not** open a public issue     |

## Response time

We aim to respond to all issues within **5 business days**.
